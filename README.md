# OnlineRetail
## Introduction 
Application of association rule mining techniques to retail transaction data. Using the Apriori and FP-Growth algorithms, we aim to uncover patterns and associations in customer purchasing behavior. 
## Objectives 
1. To identify frequent itemsets in retail transactions. 
2. To generate strong association rules that reveal valuable insights. 
3. To compare the efficiency and effectiveness of Apriori and FP-Growth algorithms. 
## Dataset 
We used the "Online Retail Data Set" available on Kaggle, which contains transactions occurring between 01/12/2010 and 09/12/2011 for a UK-based online retailer.
